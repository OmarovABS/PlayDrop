# D'VORA

Telegram Mini App — витрина цифровых услуг: первая страница с карточками категорий,
за ней витрина PS5 с каталогом игр, аккаунтами и подписками. Корзина и профиль
общие для обеих страниц.

Статика: два HTML, один CSS, ноль зависимостей, ноль сборки.

## Запуск

Нужен любой статический сервер:

```bash
python -m http.server 8080
```

или

```bash
npx serve .
```

Открыть <http://localhost:8080>. Через `file://` не заработает — mini app требует
корректный origin.

## Экраны

Две страницы. `index.html` открывается Mini App по умолчанию — это витрина услуг.
Витрина PS5 живёт отдельно в `playstation.html`, её разделы переключаются хешем:

| Файл / хеш          | Экран                                                       |
|----------------------|-------------------------------------------------------------|
| `index.html`         | услуги: герой, карточки категорий, как это работает, CTA     |
| `playstation.html#games` | витрина: каталог игр по жанрам                         |
| `playstation.html#accounts` | аккаунты PS5 по регионам                          |
| `playstation.html#subscriptions` | подписки PS Plus и EA Play                |

Карточка PlayStation на странице услуг ведёт на `playstation.html#games`. Остальные
категории (AI, облако, VPN) помечены `is-soon` — своей страницы пока нет.

`main.js` перехватывает клик только по ссылкам, начинающимся с `#`. Остальные ссылки
сегмент-контрола ведут на другие файлы и работают как обычная навигация.

## Как это устроено

- **Состояние** живёт в переменных `cart` и `wishlist` и никуда не пишется — ни
  `localStorage`, ни `sessionStorage`, ни запросов. После перезагрузки всё
  возвращается к демо-данным. Это демонстрационный витринный сценарий, а не
  рабочий магазин.
- **Каталог** отрисован прямо в HTML (9 карточек плюс 4 в блоке хитов), фильтр по
  жанру — «все / RPG / Экшен / Спорт и гонки» — переключает `data-catlight` без
  перезагрузки.
- **Обложки игр** — инлайновые SVG-заглушки в base64. Заменяются на реальные
  картинки в атрибуте `src` у `<img>`; ключи лежат в объекте `COVERS` в
  `index.html`.
- **Спрайт иконок** инлайнится в начало `<body>` и подключается через `<use>`.
  Внешний `icons.svg#id` не работает в Chrome, а `fetch` ломается на `file://`.
  Новые иконки добавляются символом в этот же инлайновый спрайт — отдельного
  `icons.svg` в проекте нет.
- **Стили** лежат в `css/main.css`: дизайн-токены в `:root`, тёмная тема — в
  `@media (prefers-color-scheme: dark)`. В HTML нет ни одного `<style>` и
  `style=` кроме инлайновых точечных настроек.

## Telegram

- Подключается `telegram-web-app.js`, дальше скрипт моста в конце `index.html`.
- Тема Telegram перекрывает токены темы, добавляются классы `.tg` и учёт
  safe-area.
- Чип пользователя в навбаре, `BackButton` синхронизирован с хеш-роутингом.
- **Отправка заказа** — `tg.sendData(JSON)`. Бот получает `{order_id, user, items,
  total, currency}`. Вне Telegram кнопка «Оформить заказ» ничего не делает, и это
  ожидаемо.

## Чего нет

Бэкенда в репозитории нет намеренно. Раньше здесь лежал aiogram-бот
(`backend/main.py`, `bot.py`, `config.py`) — он удалён, файлов и логов от него не
осталось. Заказы из mini app уходят боту через `sendData`, и обработка заказа
живёт на стороне бота.
