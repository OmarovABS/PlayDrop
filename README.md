# Verdant

Статический интернет-магазин комнатных растений: витрина, вход и кабинет с корзиной,
напоминаниями о поливе и историей заказов. Ванильные HTML, CSS и ES-модули — без сборки
и без зависимостей.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
npm run dev          # npx serve .
```

или, если Node не под рукой:

```bash
python -m http.server 8080
```

Затем откройте <http://localhost:3000>.

## Структура

```
.
├── index.html              витрина: герой, полка живучих, каталог, уход, пересадка, футер
├── signin.html             страница входа
├── cabinet.html            кабинет: корзина / мои растения / история заказов
├── css/
│   ├── base.css            токены дизайна, reset, кнопки, reveal
│   ├── components.css      навигация, карточка растения, бейджи, уход, CTA, футер
│   ├── home.css            только главная страница
│   ├── auth.css            только страница входа
│   ├── cabinet.css         только кабинет
│   └── responsive.css      все брейкпоинты и prefers-reduced-motion
├── js/
│   ├── lib/                dom, format, icons, store (состояние + подписки)
│   ├── data/               plants (каталог), seed (демо-данные первого запуска)
│   ├── modules/            фичи: nav, reveal, catalog, cart, plants, orders, views
│   └── pages/              точки входа: home, signin, cabinet
└── assets/img/             локальные иллюстрации растений (SVG)
```

## Как это устроено

- **Состояние.** `js/lib/store.js` держит корзину, список растений и заказы, сохраняет их в
  `sessionStorage` и уведомляет подписчиков. Благодаря этому корзина не теряется при переходе
  между страницами. Чтобы сбросить демо-состояние — очистите сессию браузера.
- **Каталог.** `js/data/plants.js` — единственный источник правды: из него рисуются карточки
  полки и каталога, кнопки «Купить», позиции корзины и превью в истории заказов.
- **Роутинг.** Отдельные HTML-файлы вместо хеш-роутера. Внутри кабинета вкладки
  переключает `js/modules/views.js`, состояние вкладки живёт в хеше (`cabinet.html#plants`).
- **Спрайт иконок** инлайнится в каждую страницу: внешние ссылки вида `icons.svg#id` в `<use>`
  не работают в Chrome, а подключать его через `fetch` нельзя — он ломается на `file://`.
- **Картинки** — сгенерированные SVG-заглушки в `assets/img/`. Замените их на реальные
  фотографии, сохранив имена файлов, или поправьте пути в `js/data/plants.js`.
